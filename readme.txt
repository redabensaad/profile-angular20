# Reda Portfolio 🚀

This repository contains only the **static build** generated with **Angular 20** in **SSG** (Static Site Generation) mode.

It is deployed directly on **GitHub Pages** at:

👉 https://redabensaad.github.io/profile

## Main Features
- ⚡ Framework: **Angular 20**
- 🌍 Deployment: **GitHub Pages**
- 🌀 Mode: **SSG (Static Site Generation)**
- 🚫 Zoneless: without Zone.js for better performance
- 🔔 Signals API: modern reactive management
- 🎨 Custom UI with PrimeNG, RxJS, and advanced CSS
- 🌍 Multilingual: Supports dynamic translations with **@ngx-translate**

## Objective
This portfolio showcases my projects and skills in **modern front-end** development, with a focus on performance, maintainability, and the latest Angular APIs.
